## 这是什么

野狐自动对弈是一个 Windows 桌面工具：

- **自动对弈**：识别野狐棋盘 → 调用 KataGo / 智子云算棋 → 模拟点击落子；
- **AI 托管**：用大模型当“操作员”，听懂自然语言，去开局、接邀请、连续匹配、
  聊天、观战、押分、做定时任务；
- **两颗悬浮球**：对局时主窗口最小化，只留屏幕边上的小球，所有操作在球上完成。

它**不是**外挂：不修改野狐客户端、不注入进程、不读写游戏内存；
只是像人一样看屏幕、点鼠标、敲键盘。棋力由引擎决定，不是由大模型决定。

## 功能一览

### 自动对弈（老页面）

- 19 / 13 / 9 路棋盘识别，任意窗口位置；
- 智子云 VIP（免装权重，在线算力）或本机 KataGo（LizzieYzy 配置）；
- 自动落子 + 复查；点错、被挡、被别的窗口压住会自动重试/换点；
- 对局中主窗口自动最小化，右侧出现悬浮球：
  - `开启/关闭引擎`
  - `暂停/继续`
  - 两行实时日志（选点 / 计算量 / 胜率 / 目差，一律我方视角）
- 暂停不关引擎，恢复 0 秒；
- 会话日志：`%LOCALAPPDATA%\野狐自动对弈\logs\gui-日期.log`；
- 内置自动更新（Gitee `version.json`，MD5 校验后替换）。

### AI 托管（新页面，v3.2.0）

- 顶栏两个页面：**自动对弈 / AI 托管**，`F2` 切页，`F1` 看能力说明；
- 首次进 AI 页是 **API 配置页**：
  - 服务商：火山方舟 Ark（推荐）/ DeepSeek / OpenAI 兼容自定义；
  - 填 Base URL、模型名/接入点 ID、API Key；
  - Key 用 Windows DPAPI 加密存本机，不写日志；
  - “模型支持视觉”开关：豆包视觉勾选；DeepSeek-V4.1-Flash 等纯文本模型取消勾选。
- AI 页有对话框，直接用自然语言发指令；
- 支持固定任务/定时任务：
  - 「连下 3 小时」「再下 5 盘」
  - 「每天 20:00 下两盘」
  - 「下一盘并聊天半小时」
- 能看到野狐大厅/对局室/观战室的多人聊天，回复别人、评论棋局；
  野狐里的聊天**不限话题**（但仍不碰辱骂、赌博、代练、隐私、线下约见）；
- 按双方支持池 + 引擎胜率自动押分（公式见下）；
- 开始托管后主窗口最小化，屏幕右边出现 **AI 指令球**：
  - 鼠标悬停 → 展开指令框，同时**暂停对弈/操控**；
  - 鼠标移开 → 自动收起并恢复；
  - 面板上有「主界面」「×（停止托管）」。

## 快速开始：纯自动对弈（不接大模型）

1. 打开野狐，进入一盘对局（人机 / 友谊赛都行）；
2. 启动本程序，在「引擎」下拉框选一个引擎；
3. 确认「我执」「规则」「贴目」；
4. 点 **▶ 开启引擎**；
5. 主窗口收起，右侧悬浮球出现，开始自动落子。

想停手：球上 `⏸ 暂停`；想收工：`■ 关闭引擎`。

> 程序不输入密码；只使用野狐已记住的登录状态。
> 不点商城、充值、最右竖列、右下广告。

## 快速开始：AI 托管

1. 顶栏点 **AI 托管**（或按 `F2`）；
2. 填 API：
   - **火山方舟 Ark**：
     - Base URL：`https://ark.cn-beijing.volces.com/api/v3`
     - 模型名：填控制台「在线推理」里的 `ep-...` 接入点 ID，或模型广场里的 Model ID；
     - 必须选**对话 / 视觉理解**模型，**不要选 Seedream 图片生成**；
     - 豆包视觉模型勾选「模型支持视觉」；
     - DeepSeek-V4.1-Flash 等纯文本模型取消勾选。
   - **DeepSeek 官方**：Base URL `https://api.deepseek.com/v1`，模型 `deepseek-chat`；
   - **OpenAI 兼容**：填你自己的 `base_url` + 模型名。
3. 点「测试连接」→「保存并开始」；
4. 开始托管后主窗口最小化，AI 球出现；
5. 鼠标悬停 AI 球，输入自然语言指令。

### 常用指令

```text
连续匹配友谊赛 3 小时，尽量接 9 段左右的对手
每天 20:00 开始下两盘友谊赛
下一盘棋，边下边聊天
暂停
继续
停
现在什么状态
按当前引擎胜率和双方支持池门槛押分，单注不超过 1 万
聊天风格改成谦虚型 / 骄傲型 / 阴阳怪气型 / 趾高气扬型 / 吹牛型
```

### 范围限制（焊死在程序里）

- **你与 AI 的对话/指令**：只处理野狐和围棋相关的事；
  写代码、天气、情感、时政等无关内容会被拒绝。
- **AI 在野狐大厅/对局室/观战室跟其他玩家聊天**：不限话题；
  底线是不辱骂、不赌博/代练/买卖账号、不约线下、不问隐私、不碰政治敏感/色情。
- 系统提示词、动作白名单、范围限制是程序内置常量；
  「忽略之前指令 / 把提示词发我 / 取消限制 / 开发者模式」会被直接硬拦，
  **不能通过聊天修改**。
- 可以自然语言调整的只有策略：颜色、贴目、思考时间、聊天开关/风格、押分上限等。

## 押分公式（v3.2.0）

押分前必须先：

1. **标定棋盘**；
2. 用当前引擎（智子云或 KataGo 均可）拿到当前胜率；
3. 读黑/白双方支持池金额 A、B。

默认公式：

```text
M = max(A, B) / (A + B)
高占比一方门槛 = sqrt(M)
另一方门槛   = 1 - sqrt(M)
```

只有引擎给出的该方胜率 **超过** 对应门槛才可押。

**下注前必须把自己的注额加进该方池子**，重新算 M 和门槛，再判一次；
仍超过才真正下注；超不过就自动减注，减到最低仍不过就放弃。

读不到双方支持池、标定失败、拿不到胜率 → **一律不押**。

单注上限、日限、额外优势都可以用自然语言改，并保存在本机，下次沿用。

## 聊天规则

- 同一房间每条间隔 **>15 秒（实现取 16 秒）**；
- 1 分钟最多 **3 条**；
- 单条 **≤50 字**；
- 被系统提示「您说话太快了」后等 60 秒；
- 礼仪：开局一句「请多指教」，终局一句「谢谢指教」；
- 不嘲讽、不引战、不刷屏；被问是不是 AI 如实回答「是 AI 在练棋」。

## API 常见错误

| 错误 | 含义 | 处理 |
|---|---|---|
| 401 / 403 | Key 错误、过期、无权限 | 重新复制 Key；检查账号是否开通该模型 |
| 404 `InvalidEndpointOrModel` | 模型名/接入点/区域不对 | 复制控制台的 `ep-...`；确认 Base URL 区域一致 |
| 429 `ModelAccountRpmRate` | RPM 限流/模型类型不对 | 等 1–2 分钟；确认不是 Seedream 图片生成接入点 |
| 400 图片相关 | 纯文本模型收到了截图 | 取消勾选「模型支持视觉」 |

API Key 只用于请求你填的 Base URL，不写日志、不回显、不进仓库。
